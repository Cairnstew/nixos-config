# Repository Structure

Annotated tree of all non-trivial files in the repository, grouped by directory.

## Root Configuration Files

Core flake and repository metadata files.

| File | Description |
|------|-------------|
| `flake.nix` | Main flake definition: inputs, flake-parts wiring, `perSystem` pkgs/overlays |
| `flake.lock` | Locked flake input versions |
| `config.nix` | User identity (`me`), preferences, defaults, location, git, ssh, tailnet, ollamaModels, mail — consumed by `modules/flake-parts/config.nix` |
| `AGENTS.md` | Top-level policy for agents working on this repository |
| `README.md` | Human-readable project overview |
| `GOTCHAS.md` | Known footguns and fixes (check before debugging any eval/build failure) |
| `HEATMAP.md` | Task heatmap and full `my.*` option registry |
| `SECRETS.md` | agenix / agenix-manager secrets reference |
| `justfile` | Just command runner recipes |
| `.envrc` | direnv configuration for development shell |

Root scratch/artifact files (VM images, caches, ad-hoc reports) are intentionally not enumerated here.

## modules/

Reusable NixOS, home-manager, and flake-parts modules.

### modules/flake-parts/

Flake-level modules for outputs, packages, and development tools. `flake.nix` auto-imports every `.nix` file in this directory plus any subdirectory containing a `default.nix`.

| File | Description |
|------|-------------|
| `act.nix` | Local GitHub Actions testing via `nektos/act` |
| `act-fixed.Dockerfile` | Custom act image replacing the `/var/run → /run` symlink (Docker 29+ `mkdirat` workaround) |
| `caches.nix` | Binary cache substituters and public keys (Cachix, CUDA, personal) |
| `cloud.nix` | Cloud IaC via terranix: `terranix.terranixConfigurations` (gcp/aws), OpenTofu wrappers, `tf`/`tf-plan`/`tf-apply`/`tf-destroy`/`tf-show-config` apps + `packages.tf-config` |
| `config.nix` | Identity and preference option declarations consumed from `config.nix` |
| `formatter.nix` | Treefmt/nixpkgs-fmt configuration for `nix fmt` |
| `local-verify.nix` | Local CI verification jobs (eval, format, lint, flake checks) |
| `nixtest.nix` | Nixtest integration — unit/snapshot/script tests and the `nixtests-run` app |
| `nixos-flake.nix` | nixos-unified integration and primary inputs |
| MCP servers | *(declared via the `mcp-servers-nix` flake input — `mcp-servers.programs` / `mcp-servers.settings.servers` in `modules/nixos/homeManager/config.nix`)* |
| `packages.nix` | Package exports and autowiring; CI host builds force `services.tailscale` / `services.tailscale-manager` off |
| `steamlink-deploy.nix` | Steam Link Arch Linux boot medium deploy |
| `templates.nix` | Flake templates exposed via `nix flake init` |
| `test-runner.nix` | Test-runner app/package wiring |
| `README.md` | Documentation for flake-parts conventions |
| `nixos-anywhere-deploy/` | Per-host nixos-anywhere deploy packages (`deploy-<host>`, `prepare-keys-<host>`) [→ packages.deploy-<host>] |
| `secrets/` | Secrets CLI tools: `secrets-validate`, `secrets-set`, and the `.#secrets` devShell |
| `live-iso/` | Custom NixOS live ISO builder — defines `live.isos` option [→ packages.live-iso-<name>] |
| `ventoy/` | Ventoy multi-boot USB — options, answer-file generation, deploy script [→ packages.ventoy-deploy + packages.live-iso-ventoy] |
| `vm/` | Per-host QEMU VM builder — `packages.<host>-vm` / `-vm-headless` |
