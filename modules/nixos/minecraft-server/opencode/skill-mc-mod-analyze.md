# Modpack Full Analysis (packwiz)

Run **all 7 extraction tools** against a packwiz modpack and merge the results
into a single JSON document. This gives a holistic view of the pack's content
without running each tool individually.

## When to use

- **Before major pack decisions** — adding/removing mods, evaluating balance,
  understanding the full content surface.
- **Pack snapshots** — export a single file capturing the pack's complete
  mod-added content for archival or comparison.
- **Cross-cutting queries** — "show me everything this pack adds" without
  running 7 separate commands.

For single-domain queries (just ores, just mobs, etc.) use the individual
tools (`packwiz-ore`, `packwiz-mobs`, etc.) directly — they're faster and
have domain-specific flags.

## Tools

- `packwiz-analyze <pack> [--tools ore,mobs,...] [--full-export [file]]
  [--timeout N]` — **the unified scan.**

  Runs each tool with `--json`, parses the output, and merges under a
  top-level key per tool. The result is written to stdout or a file.

  | Flag | Effect |
  |------|--------|
  | `--tools ore,mobs,...` | Run a subset (default: all 7). Options: `ore`, `mobs`, `mobspawn`, `items`, `attributes`, `loot`, `recipes`. |
  | `--full-export [file]` | Write to `<pack>-analyze.json` or a custom path. |
  | `--timeout N` | Per-tool timeout in seconds (default: 300). |

  The `attributes` tool requires `attributes-dump.json` to exist. If it's
  missing or stale, run `packwiz-attributes <pack> fullExport` first (this
  launches an isolated NeoForge server, ~5-10 min).

## Output structure

```json
{
  "modpack": "AllTheTech",
  "generated_at": "2026-09-12T15:00:00Z",
  "tools_run": ["ore", "mobs", "mobspawn", "items", "attributes", "loot", "recipes"],
  "tools_succeeded": ["ore", "mobs", "mobspawn", "items", "loot", "recipes"],
  "tools_failed": ["attributes"],
  "elapsed_seconds": 45.2,

  "ore": { "summary": {...}, "effective_placed": {...}, ... },
  "mobs": { "summary": {...}, "entities": {...}, ... },
  "mobspawn": { "summary": {...}, "biomes": {...}, ... },
  "items": { "summary": {...}, "items": {...}, ... },
  "attributes": { "error": "timeout" },
  "loot": { "summary": {...}, "tables": {...}, ... },
  "recipes": { "summary": {...}, "recipes": {...}, ... }
}
```

Each tool's value is the raw JSON from `--json` output. If a tool fails,
its value is `{"error": "...", "tool": "..."}`.

### Key summary fields per tool

| Tool | Top-level keys | Summary highlights |
|------|---------------|-------------------|
| **ore** | `effective_placed`, `effective_configured`, `contested_*`, `resolution_map` | placed feature count, contested count, ores without drops |
| **mobs** | `entities` | entity count, mob count, biome coverage |
| **mobspawn** | `biomes`, `spawners` | biome count, spawner count, mob spawn coverage |
| **items** | `items`, `blocks`, `recipes` | item/block/recipe counts |
| **attributes** | `entities` | entity count, attribute count |
| **loot** | `tables` | table count, pool count |
| **recipes** | `recipes`, `crafting`, `smelting` | recipe count by type |

## Examples

```bash
# Full analysis, write to file
packwiz-analyze AllTheTech --full-export

# Only ore + mobs (fast, no server needed)
packwiz-analyze AllTheTech --tools ore,mobs

# Custom output path
packwiz-analyze AllTheTech --full-export /tmp/allthetech-snapshot.json
```

## Prerequisites

- All 7 Python scripts must exist in `opencode/tools/`: `ore.py`, `mobs.py`,
  `mobspawn.py`, `items.py`, `attributes.py`, `loot.py`, `recipes.py`.
- `attributes` tool needs `attributes-dump.json` (generated by
  `attributes_dump.py` — launches an isolated NeoForge server, ~5-10 min).
  If missing, run `packwiz-attributes <pack> fullExport` first.
- Mod jars are cached by checksum in `/tmp/mc-pack-jars/` — first run
  downloads all jars, re-runs are instant.

## Speed

Typical times (337 mods, AllTheTech):

| Tool | Time |
|------|------|
| ore | ~10s |
| mobs | ~5s |
| mobspawn | ~3s |
| items | ~5s |
| attributes | ~1s (reads cached JSON) |
| loot | ~5s |
| recipes | ~3s |
| **Total (no attributes dump)** | **~30s** |
| **Total (all 7)** | **~35s** |

The `attributes` tool itself is fast (~1s), but generating
`attributes-dump.json` requires a full server boot (~5-10 min). If the
dump is stale, run it separately first.
