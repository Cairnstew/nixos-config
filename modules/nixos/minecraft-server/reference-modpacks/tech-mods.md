# Tech Mod Families — Quick Reference

> Common tech mods grouped by ecosystem. Useful for understanding what each modpack includes.

## Storage & Autocrafting

| Mod | Description | Loader | Common In |
|-----|-------------|--------|-----------|
| **Applied Energistics 2 (AE2)** | Digital storage, autocrafting, spatial IO | Forge/NeoForge/Fabric | ATM10, FTB Skies 2, GT Community, FactoryCraft, Techmania, Chumbucket |
| **Refined Storage** | Simpler digital storage (vs AE2) | Forge/NeoForge | FactoryCraft, Create: Homestead |
| **Simple Storage** | Basic network storage | Forge | Various kitchen-sink |

## Kinetic & Mechanical

| Mod | Description | Loader | Common In |
|-----|-------------|--------|-----------|
| **Create** | Kinetic machines, trains, factories, breadboards | Forge/NeoForge/Fabric | ATM10, FTB Skies 2, Create: A&B, Create: Astral, Create+, ATTM, TECH!, Chumbucket |
| **Create: Aeronautics** | Flying machines addon | NeoForge | Create+, FTB Skies 2: Aero |
| **Create: Crafts & Additions** | Extra Create recipes | Forge | Most Create packs |
