# DragonTech Progression Guide

> Based on analysis of popular tech modpacks: Create 2 Mekanism, Neo Mechanica, Create Brassline, and Stone to Tech

## Overview

DragonTech follows a **6-stage progression system** inspired by the most successful tech modpacks. Each stage unlocks new technologies and cross-mod interactions, culminating in a dragon-powered endgame.

### Progression Philosophy

- **Linear chapters, parallel tech trees** — Each chapter focuses on one mod, but cross-mod references encourage exploration
- **Gated progression** — Later stages require mastery of earlier ones
- **Cross-mod synergy** — Items from one mod enhance another (e.g., Create's press speeds up IE's coke oven)
- **Dragon integration** — Dragon scales and breath powers enhance tech systems

## Stage 1: Getting Started (Vanilla + Dragon Basics)

**Reference:** Neo Mechanica's "Foundation" stage, Stone to Tech's "Stone Age"

### Goals
- Survive your first night with a dragon companion
- Gather basic resources (iron, diamonds, redstone, copper, zinc)
- Build basic tools and armor

### Key Quests
1. **Spawn & Survival** — Craft wooden tools, build shelter
2. **Dragon Egg** — Find and hatch your first dragon egg
3. **Dragon Feeding** — Feed raw meat to grow your dragon
4. **Resource Gathering** — Mine iron, copper, zinc, redstone
5. **Basic Armor** — Craft iron/diamond armor
6. **Enchanting Setup** — Build enchanting table and bookshelves

### Unlock Conditions for Stage 2
- [ ] Dragon hatched and fed to juvenile stage
- [ ] 64 iron ingots collected
- [ ] 16 redstone dust collected
- [ ] Basic diamond tools crafted

---

## Stage 2: Dragon Growth (Dragon Mechanics)

**Reference:** Neo Mechanica's "Productive Bees" integration, Create 2 Mekanism's exploration quests

### Goals
- Grow your dragon to adult stage
- Collect dragon scales for crafting
- Build dragon armor and harness

### Key Quests
1. **Dragon Growth Stages** — Feed dragon through 5 growth stages
2. **Scale Collection** — Harvest scales from adult dragon
3. **Dragon Armor** — Craft dragon scale helmet, chestplate, leggings, boots
4. **Dragon Harness** — Craft harness for mounted combat
5. **Dragon Flight** — Master dragon flight controls
6. **Dragon Breath** — Collect dragon breath for special crafting

### Unlock Conditions for Stage 3
- [ ] Dragon at adult stage (5th growth)
- [ ] 32 dragon scales collected
- [ ] Dragon armor full set crafted
- [ ] Dragon harness equipped

---

## Stage 3: Tech Foundations (Create + Mekanism Basics)

**Reference:** Create 2 Mekanism's "Create" chapter, Create Brassline's first mechanism

### Goals
- Build Create's kinetic power system
- Start Mekanism's ore processing chain
- Create cross-mod resource bridges

### Key Quests
1. **Create Basics**
   - Craft andesite alloy
   - Build water wheel for kinetic power
   - Craft mechanical press and mixer
   - Set up crushing wheels for ore doubling

2. **Mekanism Basics**
   - Craft bronze ingots (copper + tin)
   - Build steel casing
   - Craft enrichment chamber for 3x ore processing
   - Set up metallurgic infuser

3. **Cross-Mod Bridges**
   - Use Create's press to speed up Mekanism's infuser
   - Feed Mekanism's enriched iron into Create's crafting
   - Share shafts between Create and Mekanism generators

### Unlock Conditions for Stage 4
- [ ] Create water wheel operational
- [ ] Mekanism enrichment chamber running
- [ ] 64 bronze ingots crafted
- [ ] 16 steel ingots processed

---

## Stage 4: Industrial Revolution (IE + PneumaticCraft)

**Reference:** Chumbucket's engineering focus, FactoryCraft's IE integration

### Goals
- Build Immersive Engineering's multi-block structures
- Set up PneumaticCraft's pressurized systems
- Scale up production with industrial automation

### Key Quests
1. **Immersive Engineering**
   - Build coke oven for coal processing
   - Construct blast furnace for steel production
   - Set up crusher for ore processing
   - Build squeezer for crop automation
   - Create conveyor systems for item transport
   - Set up wire networks for power transfer

2. **PneumaticCraft**
   - Build pressure tubes for air transport
   - Set up air compressor for pressurized air
   - Create assembly line for advanced crafting
   - Build UV light box for plastic production
   - Set up programmable controller for automation
   - Deploy drones for farming and mining

3. **Cross-Mod Synergy**
   - Use IE's crusher with Mekanism's enrichment chamber
   - Feed PneumaticCraft's plastic into AE2's processors
   - Combine Create's deployer with PneumaticCraft's assembly

### Unlock Conditions for Stage 5
- [ ] IE coke oven operational
- [ ] IE blast furnace producing steel
- [ ] PneumaticCraft air compressor running
- [ ] 64 plastic sheets produced

---

## Stage 5: Digital Age (AE2 + Powah!)

**Reference:** Neo Mechanica's AE2 chapter, Create Brassline's digital mechanism

### Goals
- Build Applied Energistics 2 digital storage network
- Set up Powah! for high-end power generation
- Automate entire production with autocrafting

### Key Quests
1. **AE2 Digital Storage**
   - Craft AE2 controller and drives
   - Build storage cells (1k → 4k → 16k → 64k)
   - Set up crafting terminal and pattern provider
   - Create molecular assemblers for autocrafting
   - Add acceleration cards for speed
   - Build wireless terminal for mobile access

2. **Powah! Power Systems**
   - Craft energizing rod and orb
   - Build solar panel progression (Basic → Advanced → Nitro)
   - Set up energy cells for storage
   - Create hybrid power systems with Mekanism

3. **Full Automation**
   - Connect all machines to AE2 network
   - Automate all resource processing
   - Set up autocrafting for complex items
   - Build wireless access points

### Unlock Conditions for Stage 6
- [ ] AE2 network operational with 64k storage
- [ ] Powah! nitro solar panel built
- [ ] All machines connected to AE2
- [ ] Wireless terminal crafted

---

## Stage 6: Dragon's Dominion (Endgame)

**Reference:** Create 2 Mekanism's Ad Astra chapter, Neo Mechanica's Draconic Evolution stage

### Goals
- Master all tech trees simultaneously
- Build dragon-powered megastructures
- Face the ultimate challenge

### Key Quests
1. **Mekanism Mastery**
   - Build fission reactor for nuclear power
   - Construct fusion reactor for endgame energy
   - Craft full mekasuit armor set
   - Build quantum entangloporter for instant transport

2. **AE2 Mastery**
   - Build creative storage cell
   - Create creative energy cell
   - Master spatial storage and IO

3. **Dragon Integration**
   - Build dragon-powered generators
   - Create dragon scale megastructures
   - Use dragon breath for special crafting
   - Build dragon flight paths between bases

4. **Final Challenge**
   - Combine all tech trees into one mega-factory
   - Build the ultimate dragon lair
   - Face the final boss (if implemented)
   - Achieve "Dragon Tech Master" status

## Balance Notes

- **Ore processing:** Create (2x) → Mekanism (3x) → IE (2x + byproducts)
- **Power generation:** Water wheel → Solar → Nuclear → Fusion → Dragon-powered
- **Storage:** Chests → Iron chests → AE2 cells → Creative cells
- **Automation:** Redstone → Create deployers → PneumaticCraft drones → AE2 autocrafting
- **Dragon integration:** Scales → Armor → Flight → Breath → Megastructures
